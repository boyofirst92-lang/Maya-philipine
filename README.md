# Maya Philippines Loan Sample

A small, front-end-only loan calculator and application-form sample inspired by a Philippine digital-finance experience.

## Run locally

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Safety

This is an illustrative demo and is not an official Maya product, offer, approval, or application portal. It does not connect to Maya services and does not collect passwords, PINs, OTPs, or payment credentials. No `.env` file or secrets are included.
